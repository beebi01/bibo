# 考前衝刺題庫 (Exam Sprint Quiz)

這是一個現代化、響應式的線上測驗應用程式，專為考前衝刺設計。

## 功能特點

- **隨機題庫**：每次測驗隨機抽取題目。
- **支援複選**：完整支援單選與複選題型。
- **即時回饋**：提交後立即顯示正確與錯誤選項。
- **錯題回顧**：測驗結束後提供詳細的錯題分析與正確答案對照。
- **響應式設計**：在手機、平板與桌機上皆能完美呈現。

## 技術堆疊

- React 18
- TypeScript
- Tailwind CSS
- Vite

## 如何開始 (Local Development)

1.  複製專案
    ```bash
    git clone <your-repo-url>
    cd <repo-name>
    ```

2.  安裝依賴
    ```bash
    npm install
    ```

3.  啟動開發伺服器
    ```bash
    npm run dev
    ```

4.  建置生產版本
    ```bash
    npm run build
    ```

## 部署至 GitHub Pages

本專案已設定好相對路徑 (`base: './'`)，建置後的 `dist` 資料夾內容可直接部署至 GitHub Pages 或任何靜態網站託管服務。
